# היום של רפאל (Day Quest)
Hebrew daily-routine PWA for a 4.5-year-old: 13 stations, no-fail mini-games, a calm corner, night mode. Offline, no network calls after install, no analytics.

- `npm run dev` / `npm run build` / `npm test` (Playwright: iPhone 13 + Pixel 7 profiles)
- Content: `src/content/phrases.ts`, `src/content/stations.ts`
- Icons: `npm run icons`
